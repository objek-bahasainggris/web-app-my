✍️ Latihan Membuat Kalimat

Susun kalimat deskriptif sederhana dalam bahasa Inggris.

💬

Pola kalimat pemula

This is a/an + benda + kata sifat.

This is a green leaf.

Ini adalah daun hijau.
The + benda + is + kata sifat.

The flower is beautiful.

Bunga itu indah.
I see a/an + benda.

I see a big tree.

Saya melihat pohon besar.

Ingat: gunakan a sebelum bunyi konsonan (a book), dan an sebelum bunyi vokal (an apple).

Petunjuk: This is a green leaf.
Hasil latihan akan muncul di sini.
